⌥ For Developers — Direct JSON Endpoints

All data files are static JSON served directly from GitHub Pages. Fetch them from anywhere. No auth, no rate limit on the files themselves. 

// Current signals — updates every 30 min market hours
fetch('https://stock-porn.loyal9.app/data/signals.json')

// Full paper trade ledger
fetch('https://stock-porn.loyal9.app/data/trades.json')

// Analytics
fetch('https://stock-porn.loyal9.app/data/stats.json')

// Timestamps and filter counts
fetch('https://stock-porn.loyal9.app/data/metadata.json')

Add ?t= + a timestamp to bust cache if you're polling frequently.
